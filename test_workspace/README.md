# Test Workspace

This is a test workspace for Raven to monitor Claude Code sessions.

## Purpose

Use this directory to test file watching and event logging capabilities.

## Usage

1. Make changes to files in this directory
2. Watch the Raven UI update with events
3. Check the database and snapshots in `.raven/`

## Test Files

- `src/example.py` - Sample Python file
- `src/example.js` - Sample JavaScript file
- `config.json` - Sample configuration file
