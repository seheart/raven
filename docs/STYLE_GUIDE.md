### Heading Hierarchy Guidelines

**Principle:** Clear structure with compact data

✅ **DO:**
- Use 18px for page titles with `padding: 0 8px` on header container
- Use 15px for major section breaks (cards, panels)
- Use 14px for subsections within cards
- Keep all data/content at 11-13px for density
- Maintain visual hierarchy through size, not bold weights

❌ **DON'T:**
- Use font sizes >18px (too large for data-dense UIs)
- Use bold (700) weights (prefer 600 for headings, 400 for data)
- Make data text >13px (sacrifices information density)
- Skip hierarchy levels (confuses structure)

## ✨ Best Practices

### DO ✅

- Use CSS variables for all colors
- Maintain 4px spacing multiples
- Use monospace fonts throughout
- Keep animations minimal
- Provide clear visual feedback
- Test in all three themes
- Use semantic color tokens

### DON'T ❌

- Don't use custom colors outside theme
- Don't use non-monospace fonts
- Don't add heavy animations
- Don't use gradients (except headings)
- Don't rely on color alone
- Don't exceed 3 elevation levels
- Don't add unnecessary emoji

## 🎯 Accessibility

### Contrast Ratios

All combinations meet **WCAG AA** (4.5:1 minimum):
- Text on background: 7:1+
- Interactive elements: 4.5:1+
- Use color + text/icon for status

### Focus States

```css
:focus {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}

/* OR custom */
:focus {
  border-color: var(--accent);
  box-shadow: 0 0 0 3px color-mix(in srgb, var(--accent) 20%, transparent);
}
```

### Keyboard Navigation

- All interactive = keyboard accessible
- Logical tab order
- Escape closes modals
- Arrow keys for lists
