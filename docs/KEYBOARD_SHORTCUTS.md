# ⌨️ Keyboard Shortcuts

Raven provides keyboard shortcuts for quick navigation and common actions.

## Global

| Shortcut | Description |
|----------|-------------|
| `?` | Open documentation (including this page) |
| `Esc` | Close modals and dialogs |

## Navigation

| Shortcut | Description |
|----------|-------------|
| `1` | Overview (Dashboard) |
| `2` | Safety view |
| `3` | Agents view |
| `4` | Activity view |
| `5` | Analysis view |
| `6` | System view |

## Tips

- **Quick Navigation**: Use number keys (1-9, 0) to instantly switch between views without reaching for the mouse
- **Escape Everything**: Press `Esc` to close any modal, dialog, or overlay
- **Productivity**: Learn the shortcuts for your most-used views to dramatically speed up your workflow

## Future Shortcuts (Planned)

These shortcuts are planned for future releases:

- `Ctrl/Cmd + K` - Quick search across all data
- `Ctrl/Cmd + R` - Refresh current view
- `Ctrl/Cmd + ,` - Open settings
- `/` - Focus search input (where applicable)
- `g` then `h` - Go to home/dashboard (vim-style)
- `g` then `s` - Go to settings
- `g` then `a` - Go to agents

## Customization

Keyboard shortcut customization is not yet available but is planned for a future release. You'll be able to customize shortcuts in the settings panel.
