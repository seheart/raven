Implementation Guide for Raven

Overview

Raven is a real-time monitoring dashboard for AI coding agents like Claude Code. These styles provide a minimal, terminal-inspired interface with three theme variants: Gruvbox, Ristretto, and Tokyo Night.

Theme Selection

Apply a theme by adding the appropriate class to the body tag: 

<body class="theme--day">   
<body class="theme--dusk">  
<body class="theme--night">

CSS Variables

All colors are defined as CSS custom properties. Use these variables in your components: 

/* Base Colors */
var(--bg)           /* Background */
var(--surface)      /* Card/panel backgrounds */
var(--surface-2)    /* Alternate surfaces (darker/lighter) */
var(--text)         /* Primary text */
var(--text-heading) /* Heading text */
var(--muted)        /* Secondary text */
var(--border)       /* Border colors */

/* Status Colors */
var(--accent)       /* Primary accent (progress bars, tags) */
var(--accent-2)     /* Secondary accent (gradient end) */
var(--success)      /* Success states */
var(--error)        /* Error states */
var(--warning)      /* Warning states */
var(--info)         /* Info states */

/* Pill Colors (darker variants for white text) */
var(--pill-success) /* Success pills */
var(--pill-error)   /* Error pills */
var(--pill-mod)     /* Modified/changed pills */

Component Classes

Use these classes for common UI patterns:

.card - Container for content sections
.feed - Live feed/log container
.pill - Status pill (add .add, .del, or .mod)
.bar - Progress bar container
.btn-primary - Primary action button
.badge-* - Status badges (success, error, warning, info)

Typography

All text uses JetBrainsMono Nerd Font (with fallbacks) for a consistent terminal aesthetic. Font sizes range from 11px (labels) to 13px (body text).

Integration with Raven

To integrate these styles into your Raven monitoring dashboard:

  1. Copy the CSS from the <style> section to your project
  2. Install a Nerd Font (JetBrainsMono, FiraCode, or Hack recommended)
  3. Apply theme class to your root element (theme--night for default)
  4. Use the component classes and CSS variables in your React/HTML components
  5. Implement theme switching by toggling the body class

Example Usage

<div class="card">
  <h3>System Metrics</h3>
  <div class="meters">
    <div>
      <div class="meter-label"><span>CPU</span><span>42%</span></div>
      <div class="bar"><span style="--val:42%"></span></div>
    </div>
  </div>
</div>

Note: This style guide is designed for terminal-savvy developers building monitoring tools for AI agents. The aesthetic prioritizes data density, readability, and a minimal htop/btop-inspired interface.

}
