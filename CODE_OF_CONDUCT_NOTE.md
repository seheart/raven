## How to Add Code of Conduct

### Option 1: Use GitHub's Built-in Template (Recommended)

1. Go to https://github.com/seheart/raven3/settings
2. Scroll to "Features" section
3. Click "Set up Code of Conduct"
4. Select "Contributor Covenant" (industry standard)
5. Click "Review and submit"
6. Commit the file

### Option 2: Manual Creation

Create `CODE_OF_CONDUCT.md` in the repository root using the Contributor Covenant template:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Why This Matters

A Code of Conduct:
- Sets expectations for community behavior
- Provides enforcement procedures for violations
- Makes the project more welcoming and inclusive
- Is a GitHub community health file
